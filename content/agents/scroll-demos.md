# Scroll demos

This repository holds complete demos and experiments, separate from the scroll-story skill.

- Start each new demo or experimental direction in its own clearly named project folder. Keep its source, data, assets, package.json and lockfile together.
- Reuse the skill's reference builds as starting points; edit the demo copies here.
- Existing comparison demos may retain their multiple selectable directions. Do not split or replace them unless the user requests it.
- Treat local Git changes here as demo work, independent of the skill repository's main branch.
- Promotion to a reusable skill asset requires the user's explicit approval. Keep the candidate here until that approval, then prepare and validate the reusable asset in the skill repository. Publishing to GitHub main requires the user's authorisation.
